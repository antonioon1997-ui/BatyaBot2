# Обновление карточки тикета и распознавания заказа

## Изменения

1. В активном тикете скрыты:
   - автор;
   - отдел-отправитель;
   - отдел-получатель;
   - дата последнего обновления.

   Эти сведения показываются при открытии завершённого или отменённого тикета.

2. Строка приоритета отображается только для значений «Важный» и «Срочный».
   Обычный приоритет по умолчанию не занимает место.

3. Строка типа отображается только тогда, когда пользователь действительно выбрал тип.

4. Улучшено извлечение номера заказа. Поддерживаются, например:
   - `Заказ 12345`;
   - `По заказу 12345`;
   - `Заказ №AB-123`;
   - `Номер заказа: 12345`.

   Слова `заказать`, `заказчик`, `заказываем` больше не принимаются за указание номера заказа.

## Установка

1. Остановите бота.
2. Сделайте резервную копию текущей папки проекта.
3. Сохраните текущие `.env` и `bot.db`.
4. Распакуйте архив и замените файлы проекта.
5. Не заменяйте свою актуальную базу старой базой из архива, если после создания архива в ней появились новые тикеты.
6. Запустите:

```bat
python main.py
```

Для точечной замены достаточно заменить два файла:

- `C:\BatyaBotWhatWhereWhen\app\handlers\tickets\views.py`
- `C:\BatyaBotWhatWhereWhen\app\handlers\tickets\utils.py`
